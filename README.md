# GiantuchiAnimation

Editor web de una mascota animada. Permite:

- mover la mascota con los botones o las flechas del teclado;
- ajustar la distancia de cada movimiento;
- reproducir una animación con rebote;
- exportar la animación completa como un archivo GIF.
- usar el escenario de oficina como fondo y desplazar la mascota sobre el piso.

## Uso

Abre `index.html` en un navegador con conexión a internet. La conexión se usa únicamente para cargar `gif.js`, necesario para generar el GIF; la exportación se ejecuta en el navegador y descarga `giantuchi-animacion.gif`.
